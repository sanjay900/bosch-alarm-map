# DeviceUpdate

Indicates if the user data in the Smartkey is up to date.  - NONE : User data in the Smartkey is up to database.  - RECOMMENDED: User data has changed and the Smartkey requires an update but everything is still working without constraints.  - REQUIRED : User data has changed and the Smartkey requires an update with the Smartkey working with constraints.  - UPDATING: User data of the Smartkey is in the process of being updated. 

## Enum

* `NONE` (value: `'NONE'`)

* `RECOMMENDED` (value: `'RECOMMENDED'`)

* `REQUIRED` (value: `'REQUIRED'`)

* `UPDATING` (value: `'UPDATING'`)
