# DeviceOpState

\"The operational state of the device shows the general condition the device is in. It also specifically identifies whether the device is working properly at the moment, so that all status information is updated and commands are processed.<br> - **OK**: Device is running properly.<br> - **INIT**: Device is initializing. This should only be the case during start up. <br> - **PROGRAMMING**: The firmware or configuration of the device is being updated.<br> - **MALFUNCTION**: The device is not working properly at the moment. Any state information provided by the resource should be considered invalid. Details to the condition of the device can be taken from the incidents of the device. 

## Enum

* `OK` (value: `'OK'`)

* `INIT` (value: `'INIT'`)

* `PROGRAMMING` (value: `'PROGRAMMING'`)

* `MALFUNCTION` (value: `'MALFUNCTION'`)
