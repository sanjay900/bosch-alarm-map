# DeviceWalktest

Gives information on the walktest status. Possible values are: <br> - **NONE**: if no walktestis running for the device.<br> - **STARTED**: if walktest for the device started but device has not been successfully walktested.<br> - **SUCCESS**: a walktest is running and this device has been successfully tested in the scope of this walktest. 

## Enum

* `NONE` (value: `'NONE'`)

* `STARTED` (value: `'STARTED'`)

* `SUCCESS` (value: `'SUCCESS'`)
